# Grammar & Syntax Specification

Language Profile: Analytic / Isolating `(C)V` Cryptolang.

---

## 1. Morphological Type
- **Type:** Pure Analytic (Isolating).
- **Rule:** Words never inflect, conjugate, or take bound prefixes/suffixes.
- Every word is an independent `(C)V` token.
- Grammatical relations (tense, aspect, number, mood) are expressed through word order and separate particle words.

---

## 2. Word Classes
1. **Content Words:**
   - Nouns (objects, people, places, concepts).
   - Verbs (actions, states).
   - Adjectives / Adverbs (descriptors).
2. **Grammatical Particles:**
   - Tense / Aspect markers (past, future, continuous).
   - Logical particles (negation, question, conjunction).
   - Case / Direction markers (prepositions / postpositions).

---

## 3. Syntax (Word Order)
- **Basic Order:** **SOV** (Subject - Object - Verb).
  - Formula: `[Subject] [Object] [Verb]`
  - Example: *Person apple eat* ("The person eats an apple").

---

## 4. Phrase Structure & Modifiers
- **Adjectives:** Pre-nominal (`Adjective + Noun`). Example: *good person*, *red apple*.
- **Adpositions:** Prepositions (`Preposition + Noun`). Example: *in house*, *with fire*.
- **Full Sentence Blueprint:**
  `[Subject] + [Preposition + Noun] + [Adjective + Object] + [Tense Particle] + [Verb]`
